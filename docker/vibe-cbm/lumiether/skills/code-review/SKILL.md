# Code Review

1. Establish the intended implementation behavior.
2. Inspect the relevant changes and Git diff.
3. Examine the affected source and interfaces.
4. Identify dependency implications.
5. Check architecture and coding conventions.
6. Check correctness, security and compatibility.
7. Identify possible regressions.
8. Examine applicable tests.
9. Distinguish confirmed issues from suspected issues.
10. Report concise, actionable findings with evidence.

Do not modify source files during review.

Avoid generic recommendations not relevant to the change.
