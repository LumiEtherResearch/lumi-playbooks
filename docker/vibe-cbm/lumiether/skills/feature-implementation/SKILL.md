# Feature Implementation

1. Establish the exact requested outcome.
2. Investigate the existing implementation locally.
3. Locate relevant functions, modules and dependencies.
4. Identify existing functionality that can be reused.
5. Check architectural constraints and compatibility.
6. Prepare the smallest suitable implementation plan.
7. Implement only the required changes.
8. Follow existing coding conventions.
9. Update applicable tests.
10. Execute authorized local validation.
11. Inspect the final Git diff.
12. Report changes, validation and outstanding issues.

Avoid unrelated refactoring.

Do not introduce unnecessary dependencies.

Do not repeatedly send previously established facts
to the cloud model.
