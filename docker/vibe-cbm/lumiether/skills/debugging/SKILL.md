# Debugging

1. Identify the reported behavior and expected behavior.
2. Locate the relevant implementation.
3. Inspect relevant errors and logs.
4. Reproduce the issue locally where practical.
5. Trace the relevant execution path.
6. Examine affected dependencies and interfaces.
7. Separate verified findings from hypotheses.
8. Prepare a concise debugging context package.
9. Use cloud reasoning for complex diagnosis where needed.
10. Implement an authorized correction.
11. Run relevant local tests.
12. Report the verified outcome.

Do not send entire unfiltered logs when only a small
error section is relevant.

Do not change unrelated functionality.
