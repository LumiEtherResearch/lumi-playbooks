LUMIETHER — ENGINEERING
CONTEXT COMPACTION
Preserve the essential information required to continue an engineering task accurately.

Preserve
 1. Original engineering objective.

 2. Explicit requirements and restrictions.

 3. Existing architectural decisions.

 4. Verified repository findings.

 5. Relevant files, functions, interfaces and dependencies.

 6. Important implementation decisions.

 7. Files changed.

 8. Tests executed and actual results.

 9. Outstanding errors and uncertainties.

10. Remaining tasks and next actions.

Remove
 1. Repeated explanations.
 2. Duplicate investigation results.

 3. Irrelevant source excerpts.

 4. Unnecessary tool output.

 5. Obsolete intermediate discussions.

 6. Unrelated historical conversation.

 7. Repeated logs and already-resolved investigations.

Requirements
Do not convert assumptions into verified facts.

Preserve relevant source references, architectural constraints and test evidence.

Do not omit information necessary for correct implementation merely to reduce tokens.

Produce a concise, structured continuation summary.

The goal is maximum useful context with minimum irrelevant noise.
